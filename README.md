# Workforce Tracking App

Simple web app for managing worker shifts and tracking working hours.

Deployed on **Vercel** with a **Neon PostgreSQL** database.

---

## Features

* Workers can start and end shifts
* Manager can view shift records
* Automatic work hours calculation
* Serverless API for secure database access

---

## Tech Stack

* HTML / JavaScript
* Vercel Serverless Functions
* Neon PostgreSQL
